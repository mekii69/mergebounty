MergeBounty

GenLayer Bradbury testnet · chain 4221

Trustless bounty escrow settled by live evidence. A client locks test GEN, a worker submits evidence (a URL, e.g. a GitHub pull request), and GenLayer validators fetch the live page and judge with an LLM whether the acceptance criteria are met. Met → the worker is paid. Unmet → the client is refunded. No human judge, no oracle.
